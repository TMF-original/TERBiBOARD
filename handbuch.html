1. Start & Installation

  • Im Browser: index.html öffnen – am besten in Chrome oder Edge. Lokal per Doppelklick funktioniert alles außer Installation und Offline-Betrieb.
  • Als App (empfohlen): Wird der Programmordner als Webseite bereitgestellt (z. B. über GitHub Pages), lässt sich TERBiBOARD installieren: Chrome/Edge am PC über das Installieren-Symbol in der Adresszeile, Android über ⋮ → App installieren, iPad über Teilen → Zum Home-Bildschirm. Danach läuft es auch offline.
  • Einzeldatei für Android: TERBiBOARD_Einzeldatei.html enthält alles in einer Datei. Auf dem Gerät mit Chrome öffnen (nicht in der Vorschau einer Datei-App).
  • Beim Start erscheint kurz die Startanimation; ein Klick oder eine Taste überspringt sie.

2. Die Oberfläche

Links liegt das Menü, rechts die Tafel. Die Tafel ist eine lange, nach unten verlängerbare Fläche; gestrichelte Linien zeigen, wo beim Drucken eine neue Seite beginnt.

3. Schreiben & Zeichnen

  • Werkzeug Stift wählen (oder Leertaste zwischen Stift und Auswahl wechseln) und schreiben – mit Stift, Maus oder (bei „Finger zeichnet“) mit dem Finger.
  • Farbe: Farbfeld anklicken oder Ziffer 1–9 (1 = Schwarz), 0 = Weiß zum Überdecken.
  • Stärke: fein (1,5) · mittel (3) · Textmarker (breit, halbtransparent – Schrift darunter bleibt lesbar). Feiner einstellen mit + / −. Alle Stifte schreiben gleichmäßig breit, unabhängig vom Andruck.
  • Formen korrigieren: H macht den letzten Strich zur Geraden (zweimal: genau waagerecht/senkrecht), K zum Kreisbogen, R/L dreht um 90°. „Glätten“ steht unter Auswahl bearbeiten.
  • Schreibgitter: G schaltet aus → Linien → Karos. Das Gitter wird weder gedruckt noch gespeichert.
Die Fläche verlängert sich beim Schreiben am unteren Rand automatisch. Von Hand: E verlängern, Strg+E auf den Inhalt kürzen.

4. Text & Formeln

  • Werkzeug Text (T): Klick setzt ein Textfeld ohne Umbruch, Aufziehen erzeugt ein Feld mit fester Breite – der Text bricht dann automatisch um.
  • Bearbeitung beenden mit Esc, Strg+Enter oder Klick daneben. Vorhandenen Text per Doppelklick bearbeiten.
  • Einfügen: Strg+V ohne aktives Textfeld legt kopierten Text als neues Textfeld ab.
  • Formeln (LaTeX): $a^2+b^2=c^2$ im Text, $$\frac{1}{2}$$ abgesetzt. Ein normales Dollarzeichen schreiben Sie als \$.
  • Textbreite nachträglich: Textfeld auswählen und an den runden Seitengriffen ziehen. Größe: A⁻/A⁺ bzw. +/− bei Auswahl.

5. Auswählen & Bearbeiten

  • Werkzeug Auswahl: Element anklicken, Rahmen aufziehen oder Strg+A (alles). Mit Shift ergänzen.
  • Ziehen verschiebt, Pfeiltasten verschieben fein (Shift = noch feiner). Eckgriffe skalieren proportional, runde Seitengriffe frei.
  • Bei Auswahl wirken Farbe, Stärke, +/−, H, K, R, L auf die ausgewählten Elemente.
  • Kopieren C, Ausschneiden X, Einfügen V; Löschen mit ⌫/Entf. Rückgängig Z, Wiederholen Y.

7. Bilder, PDF & SVG einfügen

  • Bild: P, Strg+V aus der Zwischenablage oder einfach auf die Tafel ziehen.
  • PDF-Seiten: I oder PDF auf die Tafel ziehen. Seiten per Klick oder Bereich („1-3, 5“) wählen. Jede Seite belegt die linke Hälfte – rechts bleibt Platz für Notizen. Im Querformat beginnt jede PDF-Seite auf einer eigenen Druckseite.
  • SVG als Tafelbild: Eine normale SVG-Datei mit O öffnen oder hineinziehen – Linien, Formen und Beschriftungen werden zu bearbeitbaren Strichen und Textfeldern ($…$ wird als Formel gesetzt). Als unveränderliches Bild stattdessen über P.

8. Seite, Gitter & Druck

  • Format (Seite & Druck → Format): Hoch oder Quer; wird mit der Datei gespeichert. Beim Wechsel ordnet das Board den Inhalt automatisch neu an (mit Z rückgängig).
  • Seitenlinien: Die gestrichelten Linien zeigen die echten Umbrüche. Liegt ein Element im Weg, rückt der Umbruch nach oben.
  • Für Druck anordnen (A): Blöcke, die ein Umbruch schneiden würde, rutschen auf die nächste Seite; leicht zu hohe Blöcke werden eingepasst.
  • Fester Umbruch (U): Klick setzt eine rote Umbruchlinie, Klick darauf entfernt sie.
  • Drucken / PDF: Strg+P. Für eine PDF-Datei im Druckdialog „Als PDF speichern“ wählen.

9. Speichern, Öffnen & Backups

  • Speichern S (in Chrome/Edge überschreibt erneutes Speichern dieselbe Datei), Speichern unter Shift+S, Öffnen O. Format: SVG mit Bearbeitungsdaten – voll weiterbearbeitbar.
  • Export klein: verkleinerte SVG ohne Bearbeitungsdaten – zum Weitergeben.
  • SVG-Code (Datei → SVG-Code): zeigt den Code zum Kopieren, wahlweise klein oder vollständig.
  • Backups: automatisch alle 2 Minuten im Browser; B zeigt sie, Strg+B legt sofort eines an.
Backups liegen nur im jeweiligen Browser. Wichtige Tafelbilder bitte immer zusätzlich mit S als Datei speichern.

10. Zweites Fenster (Beamer)

  • F (oder Extras → Zweites Fenster) öffnet TERBiBOARD ein zweites Mal. Fenster auf das zweite Display ziehen, dort F11 für Vollbild.
  • Beide Fenster sind live gekoppelt und bearbeitbar: Striche erscheinen beim Absetzen, Text schon beim Tippen.
  • Scrollen koppeln (beim Öffnen automatisch an): Beide Fenster zeigen dieselbe Stelle oben links – egal, in welchem gescrollt wird. Ausschalten unter Extras.
  • Rückgängig wirkt auf den gemeinsamen Stand. Wird das Hauptfenster neu geladen, das zweite Fenster neu öffnen.

12. Tipps & Fragen

Auf dem Tablet scrollt der Finger statt zu zeichnen.

So ist es gewollt (Handballen werden ignoriert). Unter Extras → Finger zeichnet umschalten.

Nach einem Update sehe ich noch die alte Version.

Einmal mit Strg+F5 neu laden; eine installierte App einmal schließen und neu starten.

Die lokale index.html funktioniert auf Android/iPad nicht.

Mobile Systeme öffnen lokale HTML-Dateien nur eingeschränkt. Lösung: die Webseite (z. B. GitHub Pages) nutzen oder auf Android die Einzeldatei in Chrome öffnen.

Tafelbilder mit einer KI erstellen lassen

Eine KI kann SVG-Grafiken erzeugen, die Sie mit O als bearbeitbares Tafelbild öffnen. Am besten klappt es mit: viewBox ca. 1200 breit, Linien mit stroke, Beschriftungen als <text>, Formeln als $…$, Pfeilspitzen als kurze Linien.
